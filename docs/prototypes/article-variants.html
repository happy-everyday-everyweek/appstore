结构化的"栏"式运营 · 卡片独立、整卡点击进集合/文章

MD3 规范检查报告（对现有设计）

✓ 详情页使用 Extended FAB（MD3 规范组件）
✓ 列表行（图标 + 两行文本 titleMedium/bodyMedium）符合 MD3 List 规格
✓ 颜色使用 surfaceContainer 系列容器色（MD3 色彩 token）
△ 底栏为自定义圆形胶囊，非 MD3 NavigationBar（80dp 高 + pill 指示器 + labelMedium）；若坚持柠檬音乐视觉则属于品牌化偏离，建议保留胶囊形但统一为 3~5 项、加活动指示
△ 搜索框 48dp / 圆角 24dp，接近 MD3 Docked SearchBar（48dp+，圆角 28dp），建议圆角改为 28dp 完全对齐
△ 卡片圆角 20dp 大于 MD3 Card 默认 12dp；MD3 允许品牌化 shape 系统，16dp 是常见折中
△ "无背景卡片"在 MD3 中不属于 Card（卡片必有容器色），对应模式是裸内容区块 + 可选着色容器；本设计以 surface 为默认底色、color 可选着色，语义成立
✓ 详情页标签行（评级/开源/权限）为 Chip 类组件，符合 MD3 辅助分类用法

布局变体说明

变体 C 采用 MD3 的 Scrolling Collection 数据展示模式：分区标题 + 横向滑动整卡。适合"编辑精选 / 近期文章"多分区运营；卡片独立、不缩窄图标行，避免横向滚动内嵌的嵌套滚动问题。作为推荐页整体骨架的候选与方案 1/2/3 并列。
