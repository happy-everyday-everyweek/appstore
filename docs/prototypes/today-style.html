如何为开源应用做评级

宋易达 · 2026-08-20 · 阅读 3 分钟

应用市场的评级体系分两层：算法初评与人工调整。算法只认一个变量——Star 数。

开源应用 Star ≥ 10k 进入 C 级，低于 10k 落在 D 级；闭源应用一律 E 级，算法无权干涉。C 级以上（B / A）完全由人工判定，社区推荐票是唯一的触发通道……

Today 布局要点（本原型实现）

· 全宽大卡上下堆叠（屏宽 − 32dp，高约 230dp，圆角 22dp），无头部结构，沉浸式
· 卡片四要素：左上分类标签（小字）、底部大标题（26sp 粗体）、标题下副标题（应用数/作者）、可选背景（渐变/纯色 color / 封面大图 cover，均随包下发）
· 应用集合卡：底部可叠 3 个应用小图标做点缀（可选 emojis 字段，也可不做，示意用）
· 交互：点整卡进集合页/阅读页；集合页头顶保留缩略大卡，下方为应用列表行
· 与已定约定完全兼容：封面独立字段、color 可选着色、正文随包、类型可扩展、未知类型安全降级
· 与你前面三个方案的关系：方案 1/2/3 是"卡内信息组织"的差异，Today 是"整卡沉浸 + 信息下沉到底部"——集合内容的图标不再平铺在卡面，而是收进集合页
