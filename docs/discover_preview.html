如何为开源应用做评级
宋易达 · 2026-08-20 · 阅读 3 分钟

应用市场的评级体系分两层：算法初评与人工调整。算法只认一个变量——Star 数。

开源应用 Star ≥ 10k 进入 C 级，低于 10k 落在 D 级；闭源应用一律 E 级，算法无权干涉。C 级以上（B / A）完全由人工判定，社区推荐票是唯一的触发通道……

正文全文随推荐包一起下发，客户端离线可读，无需访问 GitHub。

让作者知道你在看 👍

推荐页 · 展示与交互约定

卡片（第一版两种类型，可扩展）
· 应用集合：title 标题 + subtitle 副标题（"N 个应用"自动折算）+ 横向图标行（前 N 个应用图标，点击图标直接进应用详情）
· 博客文章：title + subtitle（作者·日期）+ 独立封面 cover（图片 URL，独立字段，不由包名推断）
· 卡片默认无背景色（跟随主题表面色），可通过 color 字段设置推荐背景色

交互
· 应用集合卡片：点击卡片标题区 → 进入集合页（复用列表行，可批量下载）；点击图标 → 直接进应用详情
· 文章卡片：点击 → 内置阅读页，正文随包下发（增量/全量包里含全部正文），客户端不从 GitHub 拉取
· 未知类型：旧客户端显示"位置占位"，不崩溃（向前兼容）

数据
· 卡片顺序 = 推荐仓库 JSON 数组顺序
· 封面独立字段，维护者提供图片 URL（为便于离线，图片是否随包下发待定）
· 正文 content 为 Markdown 文本，打包进推荐包
